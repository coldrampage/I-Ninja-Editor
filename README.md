https://coldrampage.github.io/I-Ninja-Editor/

Level editor/viewer for I-ninja (PC)
No base game files are hosted, stored or distributed here. You must provide your own .vol/.avl files.
Test is the current main branch.

Features
Level, collision, trigger, model, script and texture viewing. Either separate or all together in the full viewer, displayed as in game.
Strat script editing through the bytecode.
Transplanting objects and their required dependencies between levels/.vol's/.avl's.
Waypoint path editing.
Trigger box editing/type conversion.
Texture replacement.
Saveable list of prefabs to copy across levels.
